## Bincom Dev Center

This repo contains all the questions and answers for bincom dev center beginner python class.

## Getting started

1. clone the repository

```bash
git clone git@github.com:tanimowodavid/bincom_dev_center.git
```

2. change directory to the bincom folder

```bash
cd bincom_dev_center
```

3. install the requirements

```bash
pip install -r requirements.txt
```

4. open and contact session and run the `answer.py` file
